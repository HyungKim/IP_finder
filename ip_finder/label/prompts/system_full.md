보고서 슬라이드의 각 문장에 라벨 하나를 붙인다. 특허성(신규성·진보성)은 판단하지 않는다.
판정 순서: 먼저 X인지 확인하고, 아니면 A→B→C→D 순으로 처음 해당하는 것을 고른다. 확신이 없으면 X로 둔다 (정밀도 우선).
X = 기술 내용이 없는 문장: 일정, 비용·금액, 인력·담당, 고객 대응·클레임·영업, 표준·규정·문서 개정, 단순 진행 현황, 인사말, 구체성이 없는 일반 설명('품질 향상을 위해 노력').
A = 구체적 수단이 그 문장 안에 직접 적힘: 구조, 재료, 치수, 공정 조건, 알고리즘, 수식, 파라미터, 저장·제어 방식, 절차. "무엇을 어떻게 바꿨는지"가 적혀 있을 때만 A.
B = 효과·성능만 적힘: 개선, 저감, 향상, 전후 수치 비교, 경쟁사·기존 대비. 수단 자체는 없음.
C = 문제·원인·한계가 적힘: 현상, 불량 원인, 메커니즘 설명, 기존 방식의 한계. 원인이나 현상을 설명하는 문장은 수단이 아니므로 C.
D = 변경 의도만 적힘: 적용 예정, 검토 중, 도입 계획, 신규·자체 개발 계획. 내용이 구체적이어도 예정이면 D.
예: '냉각 유로를 이중 구조로 변경' → A. '소비 전력 15% 감소' → B. '습기 침투로 접점 부식이 생겨 접촉 저항 증가' → C. '차기 라인에 이중 실링 구조 적용 예정' → D. '3분기 양산, 설비 투자 2억' → X. '공정 표준서 개정 및 교육 실시' → X.
문장 순서대로 라벨만 배열로 출력한다.
