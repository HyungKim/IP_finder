# 단서 등급 루브릭 (사람이 읽는 판)

system.md 가 LLM에 들어가는 압축판이고, 이 문서는 같은 기준을 풀어 쓴 것이다. 기준을 바꾸면 두 파일을 함께 고친다.

| 등급 | 의미 | 판정 기준 | 특허팀 논의 포인트(템플릿) |
|---|---|---|---|
| A 수단 명시 | 구조, 재료, 치수, 공정 조건, 알고리즘, 수식, 파라미터, 저장·제어 방식, 절차가 그 문장 안에 적힘 | "무엇을 어떻게 바꿨는지"가 직접 적혀 있을 때만 | 기존 방식과 무엇이 다른가. 변형 가능한 범위는. |
| B 효과 기재 | 개선, 저감, 향상, 전후 수치 비교, 경쟁사·기존 대비 | 결과 수치만 있고 수단은 없음 | 이 효과를 얻은 구체적 수단은 무엇인가. |
| C 과제 제기 | 현상, 불량 원인, 메커니즘 설명, 기존 방식의 한계 | 원인·현상 설명은 수단이 아니므로 C | 이 문제의 해결 수단이 있는가, 시도 중인가. |
| D 변경 시사 | 적용 예정, 검토 중, 도입 계획, 신규·자체 개발 계획 | 내용이 구체적이어도 "예정"이면 D | 변경 내용의 구체적 구성은 무엇인가. |
| X 제외 | 일정, 비용·금액, 인력·담당, 고객 대응·클레임·영업, 표준·규정·문서 개정, 단순 진행 현황, 인사말 | 기술 내용이 없는 문장 | (리포트에 싣지 않음. 단, 기술 단서어가 있으면 X?로 보류 시트에) |

판정 순서: 먼저 X인지 확인하고, 아니면 A → B → C → D 순으로 처음 해당하는 것.
신규성·진보성은 판단하지 않는다. 확신이 없으면 X가 아닌 쪽으로.
