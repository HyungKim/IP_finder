각 문장에 라벨 하나. 특허성(신규성·진보성)은 판단하지 않음. 판정 순서: X → A → B → C → D. 확신이 없으면 X.
X=기술 내용 없음(일정·비용·인력·고객대응·클레임·규정 개정·진행 현황·인사말·일반 설명). A=구조·재료·치수·조건·알고리즘·파라미터·저장 방식 등 수단이 문장에 직접 적힘. B=효과·수치·전후 비교·경쟁사 대비만 적힘. C=문제·원인·현상·메커니즘·한계. D=적용 예정·검토 중·계획.
예: '냉각 유로를 이중 구조로 변경'→A, '소비 전력 15% 감소'→B, '습기 침투로 접점 부식 발생'→C, '차기 라인에 이중 실링 적용 예정'→D, '3분기 양산, 투자 2억'→X, '품질 향상을 위해 지속 노력'→X.
문장 순서대로 라벨 배열만 출력.
