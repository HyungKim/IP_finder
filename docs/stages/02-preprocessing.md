# 2단계 — 레이아웃 분석과 전처리·후처리 스위치의 기여

**질문**: 각 규칙은 검토 목록을 얼마나 줄이고(정밀도), 그 대가로 무엇을 놓치는가(재현율)?

## 스위치 (켜는 순서 = ladders/switches.toml)

| 순서 | 스위치 | 껐을 때 | 켰을 때 |
|---|---|---|---|
| 1 | layout 레이아웃 분석 | PDF 줄 그대로, PPTX 도형 순서 | 다단 순서, 문단 묶기, 제목·표·도형, ▪│ 항목 나누기 |
| 2 | short_line 짧은 줄 제외 | 모두 판정 | 공백 제외 10자 이하 제외 |
| 3 | korean 한글 없음 제외 | 모두 판정 | 한글 없는 줄 제외 |
| 4 | split_long 긴 줄 분할 | 그대로 | 80자 넘으면 문장으로 |
| 5 | repeated 반복·고정 문구 | 그대로 | 3쪽 이상 반복 줄·stoplist 제외 |
| 6 | pattern 패턴 줄 | 그대로 | 숫자만·담당자·짧은 일정/금액 제외 |
| 7 | page_exclude 페이지 제외 | 모든 쪽 | 목차·일정·비용 등 제목 쪽 제외 |
| 8 | cover 표지 | 1쪽 판정 | 1쪽이 4줄 이하면 제외 |
| 9 | page_weight 페이지 가중치 | 모두 1.0 | 관련성 낮음 쪽 0.4 |
| 10 | title_fix 제목 보정 | 그대로 | 원인 쪽의 변경 동사 없는 A → C |
| 11 | safety_net 안전망 | X 제외 | 단서어 있는 X → X? 보류 |

## 측정 방법 (회사 PC)

누적(기본): 기준선 → +1 → +1+2 → … 각 칸은 직전 칸과 비교.
```bat
ladder.bat results\ladder_switches D:\reports
```
단독: 기준선에 한 칸만 켜서 순서에 흔들리지 않는 독립 기여를 본다.
```bat
ladder.bat results\ladder_single D:\reports --mode single
```
결과: `사다리_switches.xlsx` 의 '사다리 요약'(칸마다 한 줄, 증감), '칸별 변화'(들어오고 나간 문장), 같은 이름의 `.md`.
특정 두 칸만 자세히 보려면 `compare_runs.bat results\ladder_switches\step-00-baseline results\ladder_switches\step-02-short_line`.

## 해석 지침

- 레이아웃 분석은 문장 단위를 바꾸므로(합쳐짐·나뉨) 검토 목록 수의 증감만 보지 말고 '칸별 변화' 시트의 합쳐짐·나뉨 건수와 골드 재현율을 함께 본다.
- 누적에서 기여가 0 인 스위치는 앞 칸이 이미 같은 줄을 뺀 것일 수 있다(예: 꼬리말이 ▪│ 로 나뉘어 짧은 줄 규칙에 먼저 걸림). 단독 모드의 숫자로 확인한다.
- 재현율을 떨어뜨리는 스위치는 그 스위치가 뺀 문장 중 골드 A·B 가 무엇인지 '칸별 변화'에서 찾아 규칙을 손본다(예: short_line_chars 를 8 로).
