# 1차 분류기 7종은 어떻게 판정하는가

같은 문장 하나를 예로 든다. **"접착제를 저탄성 실리콘계로 변경하여 응력 저감"** (정답 A: 구체적 수단).

모든 분류기는 입력이 같다(`classify/base.py` 의 `Batch`: 문장 목록, 임베딩 벡터(필요한 것만), 페이지 유형)
출력도 같다(`Prediction`: 등급, 신뢰도 0~1, 등급별 점수). 차이는 "문장을 숫자로 어떻게 바꾸고, 그 숫자로 등급을 어떻게 고르나"뿐이다.

## 먼저: 임베딩이란

임베딩 모델(bge-m3)은 문장을 **숫자 1,024개짜리 벡터**로 바꾼다. 뜻이 비슷한 문장은 가까운 벡터가 된다
("접착제를 변경" 과 "접착 재료를 바꿈" 은 가깝고, "비용 2억 원" 과는 멀다). 두 벡터가 얼마나 같은 방향인지를 **코사인 유사도**(1 = 같은 방향, 0 = 무관)로 잰다.
임베딩을 쓰는 분류기 다섯(proto·knn·centroid·softmax·ovr)은 모두 이 벡터 위에서 동작하고, 둘(cue·ngram)은 임베딩 없이 동작한다.

## 1. proto — 원형 문장 코사인 (제로샷, 학습 없음)

- 준비: 등급마다 사람이 적어 둔 예시 문장(`prototypes.json`, A 9개 B 8개 C 8개 D 7개 X 9개)을 임베딩해 둔다.
- 판정: 새 문장의 벡터와 41개 예시 벡터의 코사인을 모두 구한다. 등급마다 **가장 비슷한 예시의 유사도**를 그 등급의 점수로 삼고, 점수가 가장 큰 등급이 답이다.
  예문은 A 예시 "냉각 유로를 이중 구조로 변경하여 열을 분산" 과 0.78, B 예시 "소비 전력 15% 감소" 와 0.61 … → A.
- 신뢰도: 1위와 2위 점수 차이(0.17)를 0.65 에 더해 0.82 (상한 0.9). 차이가 없으면 0.65.
- 장점: 골드가 없어도 바로 된다. 단점: 예시 문장 몇 개가 등급의 경계를 다 정하므로, 예시에 없는 표현은 엉뚱한 등급에 붙는다.

## 2. knn — 최근접 이웃 (학습형)

- 학습: 골드 문장의 벡터와 정답 등급을 **그대로 저장**한다(계산 없음).
- 판정: 새 문장과 가장 가까운 골드 문장 k 개(기본 5)를 찾아 **다수결**. 가까울수록 표가 무겁다(유사도 가중).
  이웃 5개가 A·A·A·B·A 면 점수 A ≈ 0.8, B ≈ 0.2 → A, 신뢰도 0.8.
- 장점: 골드가 늘면 즉시 반영되고 "왜 A 인가"를 이웃 문장으로 설명할 수 있다. 단점: 골드가 적거나 어느 등급이 적으면(D 5문장) 그 등급은 이웃이 되기 어려워 못 맞춘다.

## 3. centroid — 등급 평균 벡터 (학습형)

- 학습: 등급마다 골드 벡터의 **평균**을 내어 "그 등급의 대표 벡터" 5개를 만든다.
- 판정: 새 문장과 대표 벡터 5개의 코사인 → 가장 가까운 등급. 신뢰도는 코사인 5개에 소프트맥스(아래)를 씌운 확률의 최댓값.
- 장점: 가장 단순하고 적은 골드에서도 안정적. 단점: 한 등급 안에 서로 다른 유형(A 의 '구조 변경' 과 '알고리즘 추가')이 섞이면 평균이 흐려진다.

## 4. softmax — 소프트맥스 회귀 (학습형)

- 입력: 임베딩 1,024 + 단서 특성 13 (변경 동사 있음? 단위 있음? 숫자? 효과 단어? 문제 단어? 계획 단어? 비기술 단어? 길이? 페이지 유형?) = 1,037개 숫자. 열마다 평균 0·표준편차 1 로 표준화.
- 학습: 등급마다 가중치 1,037개(+편향)를 둔다. 문장 × 가중치의 합이 그 등급의 점수(로짓)이고, 5개 점수에 **소프트맥스**(지수를 취해 합이 1 이 되게)를 씌우면 등급 확률이 된다.
  정답 확률이 커지도록 가중치를 조금씩 고치는 일(경사하강)을 600번 반복한다. 가중치가 너무 커지지 않게 L2 벌점을 둔다.
- 판정: 확률이 가장 큰 등급. 신뢰도 = 그 확률. 예문: A 0.71, C 0.14, B 0.09 … → A, 0.71.
- 장점: 어떤 차원(단어 방향)이 A 를 올리고 X 를 내리는지 가중치로 남는다. 0.6.x 의 학습 분류기가 이것. 단점: 골드가 적으면 과신(확률이 실제보다 높게)하는 경향.

## 5. ovr — 일대다 로지스틱 (학습형)

- softmax 와 입력·학습 방법이 같되, 등급 5개를 한 분포로 묶지 않고 **등급마다 "이 등급이냐 아니냐" 이진 판정기 5개**를 따로 학습한다. 출력은 시그모이드 5개(각각 0~1, 합이 1 이 아님).
- 판정: 가장 큰 시그모이드의 등급. 예문: A 0.84, B 0.12, C 0.05, D 0.03, X 0.02 → A.
- 장점: 어느 판정기도 확신이 없으면 5개가 모두 낮게 나와 "모르는 문장"이 드러난다(softmax 는 합이 1 이라 어딘가는 반드시 높다). 단점: 등급 간 경쟁을 보지 않아 두 등급이 함께 높을 수 있다.

## 6. cue — 단서어 규칙 (기준선, 학습·임베딩 없음)

- 사람이 적어 둔 단어 목록(`cues.py`)으로 if-then 판정. 순서대로 처음 걸리는 규칙이 답이다.
  1. 비기술 단어(일정·비용·담당·고객·클레임·매출·회의…) → X
  2. 계획 단어(예정·검토 중·계획·추진) → D
  3. 변경 동사(변경·적용·삽입·추가·도입·제어·보정·교체…) → A
  4. 숫자+단위(%·㎛·ms·℃…) 또는 효과 단어(개선·저감·향상·감소·단축…) → B
  5. 문제 단어(원인·문제·불량·현상·한계·발생) → C
  6. 아무것도 없으면 X
- 예문은 3번 "변경" 에 걸려 A. 신뢰도는 규칙이 걸리면 0.7, 아무것도 안 걸려 X 가 되면 0.55 로 고정.
- 역할: **"기계학습 없이 단어 목록만으로 되는가"의 바닥선.** 목록에 없는 표현("바꾸어", "대체")은 놓치고, 한 문장에 "원인"과 "변경"이 함께 있으면 순서 규칙이 하나를 고르므로 거칠다.

## 7. ngram — 글자 n-gram + 소프트맥스 (기준선, 임베딩 없음)

- 문장을 **글자 2개·3개짜리 조각**으로 자른다: "접착제를 저탄성…" → "접착", "착제", "제를", … , "접착제", "착제를", "제를 ", …
  조각마다 해시 함수로 4,096칸 중 한 칸을 정해 1 을 더하고, 벡터 길이를 1 로 맞춘다. 이 4,096개 숫자가 문장의 표현이다(임베딩 모델 불필요).
- 그 위에서 4번과 같은 소프트맥스 회귀를 학습·판정한다.
- 역할: **"임베딩 모델이 꼭 필요한가"의 비교 기준.** 글자 조각은 뜻이 아니라 표면을 보므로 "변경하여" 를 배운 뒤 "바꾸어" 는 못 알아보고, 골드가 적으면 4,096차원에 과적합한다. 반대로 임베딩 분류기보다 크게 뒤지지 않는다면 임베딩 모델 없이도 되는 셈이다.

## 신뢰도의 뜻을 통일한 이유

점수 = 신뢰도 × 페이지 가중치가 분류기 종류와 무관하게 같은 뜻이어야 검토 목록/보류 경계(0.5)가 공정하다. 그래서 모든 분류기가 "1위 등급이 맞을 확률의 추정"을 신뢰도로 낸다
(proto 의 0.65+차이, knn 의 투표 비율, centroid 의 소프트맥스 확률, softmax·ovr 의 확률, cue 의 고정값). 비교 표의 정확도와 함께 신뢰도가 실제 적중률과 맞는지(보정)도 보면 좋다.

## 비교에서 무엇을 보나

`compare-classifiers` 는 학습형을 층화 5겹 교차 검증(자기가 학습에 쓰이지 않은 겹에서 판정) × 2회로 채점한다. 요약 시트의 '정확도 표준편차'보다 작은 차이는 겹 나누기 잡음이다.
cue·ngram 이 임베딩 분류기에 크게 뒤지면 "임베딩이 필요하다"는 근거가 되고, 비슷하면 임베딩 없이도 되는 것이다. 설정 `baseline_classifiers = false` 로 두 기준선을 비교에서 뺄 수 있다.
